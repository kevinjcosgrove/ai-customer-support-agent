## Public-Safety Notes

Before publishing future screenshots, remove or mask:

- Client/business names when permission has not been granted
- Customer names and contact details
- Real business phone numbers if the project is being anonymized
- Account email addresses
- API keys, tokens, webhook URLs, and credentials
- Retell agent / knowledge-base IDs
- Private client notes or transcripts

The screenshots in this repository are intended to demonstrate architecture and testing without claiming production deployment or verified business results.
